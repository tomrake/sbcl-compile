#+TITLE: A series of bash scripts to compile SBCL on MSYS2

* About
Today [[https://sbcl.org/][SBCL]] gets regular release for Windows.
In the past I have downloaded the source and compile my own using msys2 tools.
This package is a series of bash scripts that does this work for me.
I typically use the sbcl windows release to compile the sources the msys2 tools.

* The Giant I stand on
The sbcl team and [[https://solarianprogrammer.com/2019/08/20/building-sbcl-steel-bank-common-lisp-windows/][Paul Silisteanu's 2019 blog post]] that showed me a workable method to compile sbcl on msys2.


* Signed Sources
SBCL releases signed sources and binary for Linux x86-64 computers.
